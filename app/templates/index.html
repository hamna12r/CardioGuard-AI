RESTful API Documentation & Integration

Seamlessly integrate CardioGuard AI predictions and clinical explanations into electronic health record (EHR) systems, mobile apps, or cloud workflows.

Open Interactive OpenAPI / Swagger

Single Prediction Endpoint

POST /api/v1/predict

Accepts a JSON payload containing physiological patient parameters.

Example Request (cURL):

curl -X POST "http://localhost:8000/api/v1/predict" \
     -H "Content-Type: application/json" \
     -d '{
       "age": 58,
       "gender": 1,
       "systolic_bp": 145,
       "diastolic_bp": 92,
       "cholesterol": 245,
       "glucose": 125,
       "bmi": 29.3,
       "smoking": 1,
       "alcohol_intake": 0,
       "physical_activity": 0,
       "resting_ecg": 1,
       "max_heart_rate": 135,
       "chest_pain_type": 0,
       "exercise_angina": 1
     }'
